## [0.1.0] - 2026-10-20

### Added
- The Rust crate (`resolve`, `resolve_with`, `configured`, `html_head`) and its JavaScript twin, `js/simple-locale.js`.
- The rule in `SPEC.md`: the program's own variable, `SIMPLE_LANG`, the user's and the system's `locale.toml`, the system locale, the fallback, English.
- A CI workflow (formatting, Rust and JavaScript tests).
